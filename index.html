Выбери систему, на которой будешь заниматься.

01

Установи Python 3

Открой официальный сайт Python. Выбери версию, согласованную с преподавателем, и обычный Windows installer (64-bit) для компьютера с процессором Intel или AMD. Для Windows ARM нужен установщик ARM64. Embeddable package для этой инструкции не подходит.

Скачать Python для Windows ↗
  1. Запусти скачанный установщик .exe.
  2. Если есть флажок Add python.exe to PATH, включи его.
  3. Нажми Install Now и дождись завершения.

Эти шаги относятся к классическому установщику .exe. На сайте также есть Python Install Manager — у него другой порядок установки.

02

Установи бесплатную OpenIDE

Скачать OpenIDE ↗
  1. На странице загрузки найди бесплатную версию без пометки PRO.
  2. Выбери Windows и установщик под свой процессор, обычно x64.
  3. Запусти установщик и следуй его подсказкам. После установки открой OpenIDE.
03

Создай проект и выбери Python

  1. Нажми New Project / Новый проект и выбери Python.
  2. Укажи папку для занятий, например Documents/Informatika.
  3. В настройке Python Interpreter / Интерпретатор Python выбери установленный Python 3. Если предлагается виртуальное окружение, выбери свой Python как базовый интерпретатор.
  4. Если Python не найден автоматически, добавь локальный интерпретатор и укажи файл python.exe из папки установки.
  5. Создай проект и переходи к проверке ниже.

В разных версиях OpenIDE названия пунктов могут отличаться. Нужна настройка интерпретатора Python для проекта.

01

Проверь Python в своём Linux

Эта инструкция предназначена для Ubuntu, Debian и Linux Mint. Для Astra выбери соседнюю вкладку. В других дистрибутивах команды установки отличаются.

Открой приложение «Терминал» через меню программ и выполни:

python3 --version

Если Python отсутствует или нужны компоненты виртуальных окружений, используй официальные репозитории своей системы:

sudo apt update
sudo apt install python3 python3-venv python3-pip

При запросе введи пароль администратора. Если версия Python слишком старая для OpenIDE, обратись к преподавателю. Системный Python заменять не нужно.

02

Установи бесплатную OpenIDE

OpenIDE для Linux

Выбери бесплатную версию без PRO и архив Linux для своей архитектуры. Посмотреть архитектуру можно командой:

uname -m

x86_64 соответствует x64, aarch64 — ARM64. Распакуй архив через архиватор и следуй инструкции запуска на странице OpenIDE.

03

Подключи интерпретатор

Создай Python-проект. В Python Interpreter выбери установленный Python 3 либо используй его как базовый для виртуального окружения. Получить путь можно командой:

python3 -c "import sys; print(sys.executable)"

Укажи полученный путь в OpenIDE и выполни проверку ниже.

Обрати внимание на версию Python

В старых выпусках Astra может быть предустановлен Python 3.5, а репозитории могут предлагать только версии до 3.7. Это зависит от выпуска и подключённых репозиториев. Если OpenIDE не поддерживает найденный Python, установи отдельную версию 3.9–3.11, согласованную с преподавателем.

01

Скачай бесплатную OpenIDE

Скачать OpenIDE для Linux ↗

Выбери бесплатную версию без PRO, систему Linux и архитектуру своего компьютера. Скачай и распакуй архив, затем следуй инструкции запуска на сайте OpenIDE.

У OpenIDE есть собственные системные требования. Установка нового Python сама по себе не гарантирует запуск среды на старом выпуске Astra.

02

Проверь установленный Python

python3 --version

Если версия подходит для твоей OpenIDE, переходи к созданию проекта. Если среда сообщает о несовместимости — установи отдельный Python.

03

Установи инструменты для сборки

Открой терминал и обнови список пакетов:

sudo apt update

Установи компилятор GCC, утилиту make и основные инструменты сборки:

sudo apt install build-essential pkg-config

Добавь библиотеки для распространённых модулей Python:

sudo apt install libssl-dev zlib1g-dev libbz2-dev \
libreadline-dev libsqlite3-dev libffi-dev liblzma-dev \
libncurses-dev libgdbm-dev tk-dev uuid-dev

Введи пароль администратора, если система его запросит. Символы пароля могут не отображаться — это нормально.

Названия и доступность пакетов зависят от выпуска Astra. Если пакет не найден, сохрани сообщение и обратись к преподавателю для проверки официальных репозиториев.

Проверь, что инструменты установлены:

gcc --version
make --version

Обе команды должны вывести сведения о версиях.

06

Скачай Python и перейди в его папку

Исходные коды Python ↗

Выбери выпуск ветки 3.9, 3.10 или 3.11, согласованный с преподавателем. Скачай Gzipped source tarball (.tgz) и распакуй его через архиватор. Обычно папка окажется в «Загрузках».

Открой терминал. Команда cd позволяет перейти в папку. Если папка загрузок называется «Загрузки», выполни:

cd ~/Загрузки

Если она называется Downloads, используй вместо предыдущей команды:

cd ~/Downloads

Знак ~ обозначает домашнюю папку. После каждой команды нажимай Enter. Посмотри содержимое:

ls

Найди распакованную папку Python, например Python-3.11.9, и перейди в неё. Подставь номер скачанной версии:

cd Python-3.11.9

Можно набрать cd Python- и нажать Tab: терминал попробует дописать название. Регистр важен: Python и python — разные названия. Если в названии есть пробелы, заключи его в кавычки.

Снова выполни ls. Среди файлов должен быть configure. Если его нет, проверь место распаковки. Команда cd .. возвращает на одну папку назад.

05

Собери и установи Python

Находясь в папке исходников, выполни настройку:

./configure

Если настройка завершилась без ошибки, запусти сборку:

make

После успешной сборки установи Python отдельно от системной версии:

sudo make altinstall

Сборка может занять некоторое время. Переходи к следующей команде только после успешного завершения предыдущей.

Сохрани системный Python. Используй make altinstall и не заменяй /usr/bin/python3.

Ошибка после ./configure: GCC или config.log

no acceptable C compiler found in $PATH: компилятор не найден. Вернись к установке build-essential, проверь gcc --version и повтори ./configure.

C compiler cannot create executables: компилятор не смог собрать проверочную программу. Причину нужно смотреть в журнале, универсальной команды исправления нет.

See config.log for more details: подробности находятся в файле config.log в папке исходников. Посмотреть конец файла:

tail -n 80 config.log

При обращении к преподавателю приложи сообщение из терминала и файл config.log целиком: причина может находиться выше последних строк.

Если отсутствуют модули _ssl, _sqlite3 или _tkinter, потребуются соответствующие библиотеки разработки. После их установки повтори настройку и сборку. Для новой попытки проще распаковать исходный архив заново в отдельную папку.

04

Укажи путь к Python в OpenIDE

Создай Python-проект через New Project / Новый проект. В настройке Python Interpreter / Интерпретатор Python добавь существующий локальный интерпретатор.

Для Python 3.11 при стандартной установке путь обычно такой:

/usr/local/bin/python3.11

Для версии 3.9 или 3.10 имя файла будет python3.9 или python3.10. Выбирай установленный исполняемый файл, а не архив или папку исходников. Если создаёшь виртуальное окружение, используй этот файл как базовый интерпретатор.

Проверить установленную версию можно так:

/usr/local/bin/python3.11 --version
01

Установи Python для macOS

Python для macOS

Наличие подходящего Python на Mac не гарантировано. Установим отдельный учебный Python с официального сайта.

  1. Выбери версию, согласованную с преподавателем, с установщиком macOS installer (.pkg). Проверь поддержку своей версии macOS.
  2. Открой «Загрузки» в Finder и дважды нажми на скачанный .pkg.
  3. Следуй шагам установщика: Continue / Продолжить, ознакомься с лицензией, затем Install / Установить. При необходимости введи пароль Mac.
  4. После установки открой «Программы» → Python 3.x и запусти Install Certificates.command. Дождись окончания и закрой окно.

Открой «Терминал» через Spotlight (Command + пробел) и проверь:

python3 --version

Команда python upgrade для обновления Python не используется. Если нужен другой выпуск, скачай его установщик. Системные компоненты macOS не удаляй.

02

Установи OpenIDE на Mac

Бесплатная OpenIDE
  1. Открой меню Apple → «Об этом Mac». В строке «Чип» Apple M1/M2/M3/M4 и новее означает Apple Silicon. Если указан процессор Intel, нужна версия Intel.
  2. На сайте выбери бесплатную OpenIDE без PRO и подходящий .dmg для macOS.
  3. Открой .dmg и перенеси OpenIDE в папку Applications / «Программы».
  4. Дождись копирования и запусти OpenIDE из «Программ». Подтверди обычный запрос первого открытия приложения из интернета.

Если macOS сообщает о вредоносном или повреждённом файле, остановись и обратись к преподавателю.

03

Создай проект и подключи Python

  1. Выбери New Project → Python и папку для занятий.
  2. В Python Interpreter добавь существующий локальный Python. Если создаётся виртуальное окружение, выбери его как базовый интерпретатор.
  3. Для установки с python.org путь обычно выглядит так: /Library/Frameworks/Python.framework/Versions/3.x/bin/python3. Вместо 3.x будет номер установленной версии.

Узнать точный путь можно в терминале:

python3 -c "import sys; print(sys.executable)"

Выбери этот файл в OpenIDE, затем выполни проверку ниже.

ПОСЛЕДНИЙ ШАГ

Проверим: всё работает?

В проекте создай Python-файл main.py, вставь код и запусти его через контекстное меню файла: Run / Запустить.

import sys

print("Всё работает!")
print(sys.version)
В консоли появилось «Всё работает!»?

Проверь версию в следующей строке. Если это выбранный Python — компьютер готов к занятиям!

ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

Разберёмся

OpenIDE не видит Python

Проверь, что Python установлен. В настройках интерпретатора проекта добавь путь к python.exe в Windows или к /usr/local/bin/python3.11 в Linux, если ставил версию 3.11 стандартным способом.

Код не запускается

Убедись, что файл называется main.py, для проекта выбран Python и ты запускаешь именно этот файл. Скопируй проверочный код без изменений.

Сборка в Astra завершилась ошибкой

Не продолжай установку после ошибки. Сохрани её текст и обратись к преподавателю. Состав зависимостей и совместимость библиотек отличаются между выпусками Astra.

Нужна помощь преподавателя

Пришли текст ошибки или снимок окна. Укажи свою систему, версию Python и шаг, на котором возникла проблема.

LibreOffice

Для занятий будем использовать Writer для текстов и Calc для таблиц. LibreOffice бесплатен. При выборе версии ориентируйся на требования своей системы и рекомендации преподавателя.

В Linux и Astra LibreOffice часто уже установлен, но это зависит от системы. Проверь меню программ: Writer и Calc. Если их нет, попроси преподавателя помочь с установкой из репозитория.

01

Скачай официальный установщик

Скачать LibreOffice
  1. Открой ссылку выше. Выбери Windows и архитектуру: для большинства компьютеров — x86-64, для Windows на ARM — ARM64.
  2. Узнать тип системы можно в «Параметры» → «Система» → «О системе».
  3. Скачай основной установщик .msi. Дождись завершения загрузки. Пожертвование на сайте добровольное, оплачивать программу не нужно.
Внимательно проверяй, что устанавливаешь

Переходи по официальной ссылке, а не по рекламной кнопке в поиске. Читай каждый экран установщика. Если предлагают Яндекс Игры, другой браузер, расширения или посторонние программы, отмени установку и покажи файл преподавателю. Такие предложения не нужны для LibreOffice и не являются обычным шагом его официального MSI-установщика.

02

Установи LibreOffice

  1. Открой Проводник → «Загрузки» и дважды нажми на скачанный .msi.
  2. В мастере установки нажми «Далее».
  3. Выбери «Обычная» / Typical. Для выбора языка вручную используй «Выборочная» / Custom и включи русский интерфейс в разделе языков интерфейса.
  4. Если предлагают связать документы Microsoft Office с LibreOffice, реши, какой программой хочешь открывать их по умолчанию. Для занятий менять это необязательно.
  5. Ярлык на рабочем столе можно оставить. Нажми «Установить», проверь ожидаемый запрос Windows на изменение устройства и дождись окончания.
  6. Нажми «Готово» и открой LibreOffice через меню «Пуск».
03

Включи русский интерфейс

Отдельный русификатор для Windows обычно не нужен: языки интерфейса входят в основной установщик.

  1. Открой Tools → Options → Languages and Locales → General. В старых версиях: Language Settings → Languages.
  2. В User interface выбери Russian / Русский, нажми OK и перезапусти LibreOffice.
  3. Если русского нет в списке, закрой программу, снова запусти установщик той же версии, выбери Modify / Изменить и добавь русский язык интерфейса.

Help for offline use — это справка без интернета, а не русификатор интерфейса.

  2. Для Apple M-серии выбирай macOS Apple Silicon, для процессора Intel — macOS Intel.
  3. На официальной странице скачай основной .dmg. Проверь, что выпуск поддерживает твою версию macOS.

02

Перенеси LibreOffice в «Программы»

  1. Открой Finder → «Загрузки» и дважды нажми на основной .dmg.
  2. В открывшемся окне перетащи значок LibreOffice на значок Applications / «Программы».
  3. Дождись завершения копирования. Открой LibreOffice из папки «Программы» и подтверди обычный запрос первого запуска.

03

Установи русский языковой пакет

Русский языковой пакет — официальный сайт
  1. На странице загрузки выбери ту же версию LibreOffice и ту же архитектуру Mac, что для основной программы.
  2. В дополнительных языковых пакетах выбери Russian / Русский и скачай Translated User Interface / «Переведённый интерфейс». Если его не видно, открой Other Versions & Installation Methods или список файлов. Нужен пакет с langpack_ru в названии.
  3. Открой скачанный .dmg языкового пакета и запусти установщик внутри.
  4. Следуй подсказкам. Если потребуется выбрать программу, укажи LibreOffice.app в папке «Программы».
  5. Снова открой LibreOffice. В LibreOffice → Preferences / Settings → Languages and Locales → General выбери User interface → Russian. В старых выпусках раздел называется Language Settings → Languages.
  6. Подтверди выбор и полностью перезапусти LibreOffice.

Номер версии и архитектура языкового пакета должны совпадать с основной программой. Пакет справки Help for offline use не меняет язык меню.

ПРОВЕРКА

Открой Writer и Calc

  1. В стартовом окне LibreOffice выбери «Документ Writer». Напиши «Всё работает!» и сохрани файл через Файл → Сохранить как в формате .odt.
  2. Создай «Таблицу Calc». В ячейку A1 введи =2+2 и нажми Enter. Должно получиться 4.
  3. Сохрани таблицу в формате .ods, закрой и открой оба файла снова.

Для учебных заданий используй формат, который указал преподаватель. Если нужен .docx или .xlsx, выбери его в «Сохранить как» и подтверди сохранение в выбранном формате.

Не получилось установить или включить русский язык

Пришли преподавателю версию системы, процессор, версию LibreOffice, название установочного файла и текст ошибки. Если русский язык не появился, сначала проверь совпадение версий программы и пакета.
