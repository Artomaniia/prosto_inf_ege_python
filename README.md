# Инструкция Python + OpenIDE

Статический сайт для GitHub Pages. Сборка и установка пакетов не нужны.

## Публикация

1. Создайте репозиторий на GitHub (для бесплатного GitHub Pages обычно публичный).
2. Распакуйте архив и загрузите содержимое папки site в корень репозитория: index.html, style.css, script.js, assets и .nojekyll. Не загружайте сам ZIP вместо файлов.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Source: Deploy from a branch.
5. Выберите ветку main и папку / (root), нажмите Save.
6. Дождитесь публикации. Ссылка появится в Settings → Pages, обычно https://ИМЯ.github.io/РЕПОЗИТОРИЙ/.

Если репозиторий называется ИМЯ.github.io, сайт откроется по https://ИМЯ.github.io/.

Открыть index.html можно и напрямую на компьютере. Копирование команд работает на HTTPS или localhost; при открытии файла код можно скопировать вручную.

## Изменения

Тексты и ссылки находятся в index.html, оформление в style.css, переключение вкладок и копирование в script.js.
Декоративные элементы извлечены из предоставленной презентации. Шрифты Manrope и Oswald загружаются через Google Fonts; без сети используются системные шрифты.

Инструкция Astra описывает общий порядок. Сборка Python и установка OpenIDE в виртуальной машине не проверялись. Набор зависимостей и совместимость OpenIDE зависят от выпуска Astra. Системный Python заменять не следует.


## Разделы сайта

Python + OpenIDE: Windows, Ubuntu/Debian/Mint, Astra Linux, macOS. LibreOffice: Windows и macOS, включая русский интерфейс и проверку Writer/Calc.
Сборка и установка приложений на перечисленных ОС в рамках этого обновления не выполнялись.
